Un manual web interactivo, rápido y *responsive* para la consulta de las transacciones (T-Codes) más utilizadas en **SAP ECC** y **SAP S/4HANA**.

Diseñado especialmente para consultores, analistas funcionales, usuarios clave (*key users*) y operadores del día a día en áreas como **Compras (MM-PUR)**, **Gestión de Inventarios (MM-IM)**, **Verificación de Facturas (MM-IV)**, **Finanzas (FI)** y **Producción de Procesos (PP-PI)**.

\---

## 🚀 Características

* ⚡ **Búsqueda en tiempo real:** Filtra instantáneamente por código de transacción (`T-Code`), palabra clave o función de negocio.
* 🏷️ **Filtrado por módulo/categoría:** Selecciona fácilmente áreas específicas como Compras, Inventarios, Finanzas, Maestros, Producción o Reportes.
* 📱 **Diseño Responsive:** Adaptado para visualizarse correctamente en computadoras de escritorio, tablets y dispositivos móviles.
* 🎨 **Interfaz Fiori-Style:** Estilo visual limpio inspirado en las guías de diseño de SAP Fiori.
* 📦 **Sin dependencias externas:** Desarrollado con HTML, CSS y JavaScript nativo (*Vanilla JS*). No requiere servidores ni instalación de librerías.
* 🔄 **Compatibilidad S/4HANA:** Incluye equivalencias de transacciones unificadas como `BP` (Business Partner) y notas sobre códigos legacy.

\---

## 📋 Módulos y Cobertura Incluida

|Categoría|Módulo SAP|Ejemplos de T-Codes|
|-|-|-|
|**Compras**|MM-PUR|`ME21N`, `ME22N`, `ME51N`, `ME31K`, `ME41`|
|**Inventarios**|MM-IM|`MIGO`, `MB51`, `MB52`, `MI01`, `MI04`|
|**Maestros**|MM / SD / FI|`MM01`, `XK01`, `FK03`, `BP`, `MMSC`|
|**Facturación**|MM-IV|`MIRO`, `MIR7`, `MRBR`, `MR8M`|
|**Finanzas**|FI / CO|`FB50`, `FB60`, `FBL1N`, `FBL5N`, `F110`, `FS00`|
|**Producción**|PP-PI|`COR1`, `COR2`, `COR6N`, `CO60`, `COID`|
|**Reportes**|MM / FI|`MMBE`, `MB5T`, `ME2N`, `ME2L`|
